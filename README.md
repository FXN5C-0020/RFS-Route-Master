✈️ RFS 航线大师 V3.6（全库同步定稿版）
一款面向 Real Flight Simulator（RFS）玩家的航线规划辅助工具，旨在为模拟飞行爱好者提供方便、直观的航线规划体验。

工具支持机场搜索、连续航段编辑、机型筛选与推荐、飞行参数估算、地图显示，以及 TXT、JSON、KML 文件导入导出。项目为单文件网页应用，可直接用现代浏览器打开，也可部署到 GitHub Pages。

🌍 主要功能
1. 航线规划与地图
支持通过 ICAO 四字代码、IATA 三字代码或机场名称搜索机场。
支持添加多个连续航段，以及撤销末段、删除指定航段、清空航线和交换机场。
使用大圆航线算法估算航段距离与初始航向，并在地图上绘制航线。
支持从地图选择机场、定位航线和全屏显示。
移动端提供分屏、航线参数和全屏地图视图。
RFS 单次计划参考上限为 5 段；超过时会显示提示，但不会强制阻止继续添加或计算。

2. 多种地图模式
目前提供三种地图显示模式：

Google 卫星地图：在线卫星影像。
CARTO 暗色地图：在线暗色风格底图。
Canvas 离线矢量地图：使用 Canvas 绘制简化经纬网和机场位置，不加载在线地图底图。

Leaflet、在线机场数据以及 Google / CARTO 地图图块需要网络连接。Leaflet 资源加载失败时，页面会切换到 Canvas 交互画布作为备用地图。离线模式提供的是简化示意图，不包含真实地形、国界、空域或导航设施信息。

3. 飞机数据库
内置 59 架参考机型，涵盖 Airbus、Boeing、Embraer、ATR、Bombardier、Cessna、COMAC、McDonnell Douglas 等制造商和机型，可按制造商与系列筛选。

提供以下参考参数：

飞机参考最大航程
参考巡航速度
参考小时油耗
燃油容量上限
参考载客量

工具可根据最长航段和乘客人数进行基础机型推荐。所有机型性能数据均为程序内置参考值，并非实时数据或经认证的飞机性能数据。

4. 飞行计划计算
支持设置或调整：

航班号 / 呼号
乘客人数与货物重量
巡航高度与巡航速度
平均风分量
航路绕飞系数
油耗修正
额外机动油比例
备降及保底油时间

计算后生成简易 OFP（Operational Flight Plan），显示预计航程、初始航向、飞行时间、估算燃油量及超航程、超油箱或超座位等提示。计算使用简化的模拟估算模型，不等同于真实签派或飞行性能计算。

5. 文件导出与导入
支持以下格式：

TXT：导出模拟飞行计划。
JSON：导出或导入航线、机场坐标、机型和参数工程数据。
KML：导出采样的大圆航线，可用于支持 KML 的地图软件或模拟器工作流。

KML 航迹会对首尾机场附近的长航段进行近场裁切，以便配合 RFS 的离场 / 进场处理；具体导入效果取决于目标软件。

🚀 使用方法
下载项目文件，或将仓库部署到 GitHub Pages。
使用现代浏览器打开 index.html。
输入出发和到达机场的 ICAO、IATA 代码或机场名称，并从搜索结果中选择机场。
点击「添加航段」建立航线；如有经停，可继续添加下一段。
选择机型并设置乘客、货物及飞行参数。
点击「计算完整计划」查看估算结果。
根据需要导出 TXT、JSON 或 KML 文件。

⚠️ 已知问题与限制（Known Issues）
白令海峡及国际日期变更线附近的航线显示
此前跨越白令海峡或东西半球分界线附近时可能出现的航线断裂显示问题，已在当前版本中通过经度连续性处理进行修复。当前代码对 Leaflet 航线坐标进行连续经度处理；建议使用当前版本，不要沿用旧版文件。

浏览器实测情况
本次使用 Chromium 浏览器进行桌面和移动视口冒烟测试：机场库同步到 49,345 条记录，59 个机型均可显示；机场搜索、添加航段和生成计划正常；离线 Canvas 地图图层可显示；在 390px 宽移动视口下未发现页面横向溢出，也未发现页面级 JavaScript 运行错误。

以上仅代表本次 Chromium 测试环境，不代表所有 Chrome、Firefox、Safari 或不同手机设备均已逐一验证。浏览器会请求网站图标；当前项目未提供 favicon，因此可能出现图标 404 请求，不影响主要功能。

其他限制
全球机场数据库依赖网络加载；首次同步较慢或网络异常时，将使用内置机场数据或此前保存在浏览器中的机场缓存。
Google 卫星地图和 CARTO 暗色地图依赖第三方在线服务；离线时请切换到 Canvas 模式。第三方服务可用性及使用条件由对应提供方决定。
Canvas 地图是简化示意图，不提供真实地图细节。
机型航程、油耗、燃油量和飞行时间均为模拟近似计算，不能用于真实航空飞行、导航或签派决策。
当前航段上限为提示而非强制限制：超过 5 段仍可继续计算和导出，但可能超出 RFS 游戏支持范围。
