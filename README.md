✈️ RFS 航线大师 V2.0 Beta

一款面向 Real Flight Simulator（RFS）玩家的航线规划辅助工具，旨在为模拟飞行爱好者提供更加方便、直观的航线规划体验。

通过机场搜索、航段编辑、机型选择、飞行参数计算以及多种文件导出功能，帮助玩家在模拟飞行前制定自己的飞行计划。

🌍 主要功能

1. 航线规划与地图

- 支持通过 ICAO 四字代码或机场名称搜索机场。
- 支持添加多个连续航段。
- 支持航段撤销、删除、清空和机场交换。
- 使用大圆航线算法绘制机场之间的航线。
- 支持地图缩放、航线定位及全屏显示。
- 支持动态机场标注。

2. 多种地图模式

目前提供三种地图显示模式：

- Google 卫星地图：查看卫星影像。
- CARTO 暗色地图：提供暗色风格的地图显示。
- Canvas 离线矢量地图：使用 Canvas 绘制简化世界地图及机场位置。

3. 飞机数据库

支持 Airbus 和 Boeing 部分机型的筛选与选择。

提供以下参考参数：

- 飞机参考航程
- 参考巡航速度
- 参考小时油耗
- 参考最大燃油量

并提供基础机型航程匹配推荐功能。

4. 飞行计划计算

支持自定义：

- 乘客人数
- 货物重量
- 巡航高度
- 巡航速度
- 平均风分量
- 航路绕飞系数
- 油耗修正
- 额外储备油
- 备降油
- 最终储备油

计算后生成简易 OFP（Operational Flight Plan），显示预计航程、飞行时间、建议燃油量及航段信息。

5. 文件导出

支持三种格式：

- TXT：导出飞行计划。
- JSON：导出航线机场数据。
- KML：导出大圆航线文件，可用于支持 KML 的地图软件。

🚀 使用方法

1. 下载项目 HTML 文件。
2. 使用现代浏览器打开 HTML 文件。
3. 输入出发机场和到达机场。
4. 从机场搜索结果中选择对应机场。
5. 点击添加航段，建立自己的航线。
6. 选择飞机并设置飞行参数。
7. 点击「计算完整计划」生成飞行计划。
8. 根据需要导出 TXT、JSON 或 KML 文件。

⚠️ 已知问题与限制（Known Issues）

白令海峡附近航线显示断层

目前，在地图区域显示跨越白令海峡、跨越东西半球分界线（国际日期变更线附近）的航线时，可能出现航线显示断层或不连续的情况。

该问题与当前地图绘制及经度跨越处理有关。

由于作者目前技术能力有限，暂时无法彻底解决这一问题。该问题将在后续版本中视情况研究和改进。

目前建议用户在规划此类跨半球航线时，以机场坐标和航段距离计算结果为参考，不要完全依赖地图上的航线显示。

其他限制

- 全球机场数据库依赖网络加载，网络异常时将使用内置机场数据。
- 在线卫星地图和暗色地图需要网络连接。
- Canvas 模式仅提供简化的离线地图显示。
- 部分机型性能参数为程序内置参考值，并非真实飞机实时性能数据。
